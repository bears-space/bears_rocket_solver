** Package notes

*** OpenMDAO

[[https://openmdao.org/][OpenMDAO]] is the multidisciplinary optimizer that will tie the whole solver
program together. OpenMDAO works by organizing large calculations into groups
and subsystems into Python classes

| Component type | Inputs | Outputs        |
|----------------+--------+----------------|
| IndepVarComp   |        | $P_t$          |
| IndepVarComp   |        | $a_\text{o/f}$ |
| ImplicitComp   |        | -              |
| ExplicitComp   |        | -              |

*** CEA

[[https://www.nasa.gov/glenn/research/chemical-equilibrium-with-applications/][CEA]] is NASA's isentropic chemistry solver that will be used for chemical
computations

We use [[https://rocketcea.readthedocs.io/en/latest/index.html][RocketCEA]] instead of the plain [[https://nasa.github.io/cea/interfaces/python_api.html][CEA Python interface]] because that package
is intended specifically for rocketry development

CEA doesn't understand the full chemistry of polymer reactants, and polymers
are modelled with a pseudo-species of fixed polymer chain length
